### 🚀 What I'm building

I turn ideas into shipped apps — web, mobile, and everything wired behind them. Two projects lead the way:

#### 🌙 [Battut](https://app.battut.app) — a Shariah-compliant social platform
Instagram/Twitter for the Muslim community, built with values first. Ships as a PWA **and** native iOS/Android from one codebase, with a moderation dashboard, an advertiser portal, and a marketing site.
- **Stack:** React 19 · Vite · TypeScript · TailwindCSS · Firebase (Firestore / Auth / Functions / Storage) · Capacitor · Cloudflare Workers + R2 · Turborepo
- **Ideas inside:** community moderation (*Shariah Guard*), a watch-to-earn token, client-side benefit-first feed ranking, and full RTL/i18n.

#### 🌾 JomLocal — hyperlocal discovery for Perlis, Malaysia
A two-sided, fully bilingual (EN / Bahasa Melayu) platform: locals discover authentic places — kopitiams, night markets, padi fields, mosques — while businesses advertise through a token-powered ad marketplace.
- **Stack:** Expo / React Native · Next.js 15 & 16 · Drizzle ORM · Neon Postgres · Firebase Auth · Zustand

> 👀 Poke around my other repos too — there's more cooking (AI tooling, mobile apps, a few experiments).
